w01-9 函数、返回值、作用域、文档字符串

课文已遮住 · 先回想重点再核对

  • return 把值交回调用者；没有 return 相当于返回 None
  • 不要用 print 代替 return：print 给人看，return 给下一行代码用
  • 一个函数尽量一件事；名字用动词或名词短语
  • 默认参数必须在普通参数后面：def chat(user, temperature=0.2):
  • 不要用 [] 或 {} 当默认值（可变对象会在多次调用间共享）。要用 None 再在里面新建

作用域：函数内赋值的变量默认是局部的，看不见外面的同名变量（除非 global，应用代码里尽量别用 global）。
