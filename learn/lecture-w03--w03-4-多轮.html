w03-4 多轮

无状态： 每次 HTTP 彼此独立。网页能「记住」，是因为又把历史发给模型。

  1. history 先放 system
  2. 用户一句 → append user
  3. 调接口 → append assistant（content 原样）
  4. 下一轮把整个 history 发出去

太长要截断（留 system + 最近 N 轮）。本周先不截，但要知道。
