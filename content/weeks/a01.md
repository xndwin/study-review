## 程序怎么往下走

Python 从第 1 行按顺序一行行往下执行：
- **`print(...)`**：把括号里的计算结果显示到屏幕。
- **`#`**：井号后面整行是注释备注，运行时直接跳过。

### 区分 `=` 和 `==`

| 符号 | 含义 | 例子 |
|---|---|---|
| `=` | **赋值**：先算右边，再存进左边变量 | `score = 60`（把 60 装进 `score`） |
| `==` | **判断相等**：两边值一样得 `True`，否则得 `False` | `score == 60`（中间不能有空格） |

```python
score = 60
print(score == 60)  # True
print(3 == "3")     # False：3 是整数 int，"3" 是文字字符串 str，类型不同
```

## 第 1 天：比较和布尔

布尔值（`bool`）只有两个：**`True`（真）** 和 **`False`（假）**。注意在代码里**首字母必须大写**。

### 1. 六个比较符号

符号中间不能加空格：

| 写法 | 意思 | 例子 | 结果 |
|---|---|---|---|
| `==` | 等于 | `5 == 5` | `True` |
| `!=` | 不等于 | `3 != 4` | `True` |
| `>` / `<` | 大于 / 小于 | `2 < 1` | `False` |
| `>=` | 大于或等于（至少） | `5 >= 5` | `True` |
| `<=` | 小于或等于（至多） | `60 <= 100` | `True` |

### 2. 逻辑连接：`and`、`or`、`not`

- **`and`（并且）**：左右**都为 `True`** 才得 `True`，有一边假就是 `False`。
- **`or`（或者）**：左右**至少一边为 `True`** 就得 `True`。
- **`not`（取反）**：真变假，假变真。

```python
print(3 > 2)            # True
print(3 != 4)           # True
print(5 >= 5)           # True
print(2 < 1)            # False
print(True and False)   # False
print(False or True)    # True
print(not True)         # False
```

### 3. 真假转换规则：`bool(...)`

记住两句话：**数字看是不是 0，字符串只看空不空。**
- **数字**：`0` 和 `0.0` 是 `False`，其余非零数字都是 `True` → `bool(0)` 为 **`False`**。
- **字符串**：只有没字符的空串 `""` 是 `False`；只要引号里有字符（哪怕写的是 `"0"`、`"False"` 或空格 `" "`），一律是 `True` → `bool("0")` 为 **`True`**。

### 4. 把判断结果存进变量

等号右边放判断式时，**先算右边得出 `True`/`False`，再装进左边变量**：

```python
score = 75
text = "hello"

pass_check = score >= 60          # 成绩至少 60
range_check = 0 <= score <= 100   # 0 到 100 之间（也可写 score >= 0 and score <= 100）
non_empty = text != ""            # 不是空字符串
```

## 第 2 天：输入和字符串

### 1. `input()` 永远返回字符串

哪怕用户在键盘敲数字 `60`，`input()` 拿到的也是字符串 **`"60"`**，不能直接和整数比大小。

### 2. 字符串常用方法

格式为 `字符串.方法()`：**末尾括号 `()` 不能省**；原字符串自己不变，必须用变量接住返回的新字符串。

| 写法 | 作用 | 例子 → 结果 |
|---|---|---|
| `s.strip()` | 去掉**首尾**空格与换行 | `"  Q \n".strip()` → `"Q"` |
| `s.lower()` | 字母转小写 | `"Q".lower()` → `"q"` |
| `s.isdecimal()` | 非空且全是 `0–9` 数字字符才为真 | `"60"` 为 `True`；`"60.5"`、`"-1"`、`""` 全为 `False` |
| `len(s)` | 统计字符个数 | `len("60")` → `2` |
| `repr(s)` | 连带引号和首尾空格一起显示 | `repr(" 60 ")` → `' 60 '` |

### 3. `f-string` 拼接输出

引号前加 `f`，用 `{变量}` 把值嵌进句子：

```python
raw = "  Q "
cleaned = raw.strip().lower()   # 从左往右依次去空格、转小写

print(repr(raw))                # '  Q '（原串没变）
print(cleaned)                  # q
print("60".isdecimal())         # True
print("60.5".isdecimal())       # False

name = "王敏"
print(f"你好，{name}，输入长度={len(cleaned)}")
```

## 第 3 天：分支

`if / elif / else` 语法三条规矩：
1. 每行条件末尾必须加英文冒号 **`:`**；
2. 分支内部代码必须向右缩进 **4 个空格**（按 `Tab`）；
3. **从上往下只走第一个成立的分支**，走完直接结束整组判断。

### 校验顺序不能乱

- **先查格式再转整数**：对 `"abc"` 直接调 `int()` 会崩溃，必须先用 `text.isdecimal()` 挡在门外（`"-1"` 含负号，也会在这一步被拦下）。
- **高分段排在前面**：如果先写 `>= 60` 再写 `>= 90`，`95` 分在第一条就被判成「及格」结束了，永远走不到「优秀」。

```python
raw = " 90 "
text = raw.strip()

if not text.isdecimal():
    print("错误")
else:
    score = int(text)
    if score > 100:
        print("错误")
    elif score >= 90:
        print("优秀")
    elif score >= 60:
        print("及格")
    else:
        print("不及格")
```

| 输入样本 | 预期结果 |
|---|---|
| `0`、`59` | `不及格` |
| `60`、`89` | `及格` |
| `90`、`100` | `优秀` |
| `101`、`-1`、`abc`、空串、`60.5` | `错误`（不崩溃，不输出等级） |

## 第 4 天：for 和统计变量

### 1. `range(起点, 终点)` 含头不含尾

- `range(1, 6)` 产生 `1, 2, 3, 4, 5`（共 5 个数，**不含 6**）。
- 想遍历 `1` 到 `10` 要写 **`range(1, 11)`**；遍历 `55` 到 `65` 要写 **`range(55, 66)`**。

### 2. 统计变量必须放在循环外初始化

`total = total + n`（可简写为 `total += n`）表示：先算旧 `total + n`，再存回 `total`。
如果把 `total = 0` 写进循环里面，每轮开头都会被清零！

```python
# 1 到 10 求和
total = 0
for n in range(1, 11):
    total = total + n
print(total)      # 55

# 统计 55 到 65 中 >= 60 的个数
passed = 0
for n in range(55, 66):
    if n >= 60:
        passed = passed + 1
print(passed)     # 6
```

## 第 5 天：while、退出和跳过

事先不知道要循环多少次时，用 `while True:` 搭配两个跳转词：
- **`break`**：立刻**结束整个循环**，跳到循环外往下走。
- **`continue`**：**跳过本轮剩余语句**，直接回到循环开头读下一次输入。

```python
valid = 0
while True:
    raw = input("成绩，q 退出: ")   # 必须写在循环内，每轮读新输入
    text = raw.strip().lower()
    if text == "q":
        break                       # 遇到 q 结束循环
    if not text.isdecimal():
        print("错误")
        continue                    # 非数字直接回开头，不往下计数
    score = int(text)
    if score > 100:
        print("错误")
        continue
    print(score)
    valid = valid + 1

print("有效", valid)
```

核对三组流程：
- `60 → abc → 90 → q`：有效 `2`（`abc` 在 `continue` 处跳过计数）。
- 直接 `q`：有效 `0`。
- `101 → -1 → Q`：有效 `0`（大写 `Q` 转小写后正常退出）。
