第 2 周：列表、字典、函数

计划日期：2026-11-23 到 2026-11-29。大约 20 小时。

这一周把第 1 周没覆盖的语法补上，并能把「去重、分类、排序」拆成函数。换一种输入格式之后，你要能改自己的代码，而不是重写一整页。

列表

列表有顺序，可以改。下标从 0 开始，负数从末尾数。切片含头不含尾。

scores = [59, 60, 100]
print(scores[0], scores[-1])
print(scores[0:2])
scores.append(80)
print(scores)
print(sorted(scores))
scores.sort()
print(scores)

输出：

59 100
[59, 60]
[59, 60, 100, 80]
[59, 60, 80, 100]
[59, 60, 80, 100]

sorted(scores) 交出一个新列表，原来的不变。scores.sort() 改的是原来那一个，返回 None。把 print(scores.sort()) 印出来会看到 None，这是常见错法。

不要在 for x in scores 里面 append 或 remove 正在遍历的那个列表。要过滤，就建一个新列表。

元组写成 (1, 2)，创建之后不能改某一项。只有一个元素时必须写 (1,)，否则括号只是分组。a, b = (1, 2) 叫拆包。

第 1 周留下的字符串

s = "Python"
print(s[0], s[-1], s[0:2], len(s))
print("th" in s)
print("  Q ".strip().lower().replace("q", "quit"))
print("a,b".split(","))
print("-".join(["a", "b"]))
print("python".find("th"))
print("python".find("zz"))

输出里，s[0:2] 是 Py。find 找不到时返回 -1，不是报错。split 得到列表，join 用分隔符把列表拼回字符串。

字典和集合

字典用键取值。键不存在时，person["email"] 抛 KeyError。person.get("email", "(无)") 给出默认值。

person = {"name": "王敏", "score": 90}
print(person["name"])
print(person.get("email", "(无)"))
person["score"] = 91

seen = set()
for word in ["rag", "sql", "rag"]:
    seen.add(word)
print(sorted(seen))

sorted(seen) 是 ['rag', 'sql']。集合自动去重，不保证顺序。空集合写成 set()。{} 是空字典，不是空集合。

模型返回的 JSON 变成字典之后，正文在：

text = resp["choices"][0]["message"]["content"]

先确认每一层都在，再取下一层。

循环的另外三种写法

enumerate 同时给出序号和元素，序号默认从 0 开始。zip 把两个序列并排走到较短的那个结束。

names = ["王敏", "李雷"]
for i, name in enumerate(names, start=1):
    print(i, name)

for name, score in zip(names, [90, 61]):
    print(name, score)

for / while 可以带 else。这个 else 只在循环没有被 break 打断时执行。搜一个名单，找到就 break，没找到才走 else。

and / or 会短路：左边已经能决定结果，右边就不算。0 or 5 的值是 5，3 and 7 的值是 7。它们不一定返回 True / False，返回的是最后那个被看过的操作数。

和 None 比较用 is：score is None。== 问的是值相不相等，is 问的是是不是同一个对象。

三元表达式："及格" if score >= 60 else "不及格"。能改写成普通 if 就先用普通 if。

函数

print 给人看。return 把值交给下一行代码。函数里如果只 print，调用方拿到的是 None，没法继续算。

def average(total, count):
    if count == 0:
        return None
    return total / count

print(average(219, 3))
print(average(0, 0))

输出 73.0 和 None。

默认参数不要用 [] 或 {}。那个列表会在多次调用之间共用。写成 None，进函数再新建：

def add_score(scores=None):
    if scores is None:
        scores = []
    scores.append(60)
    return scores

函数内部第一次给一个名字赋值，这个名字就是局部的，不会改外面的同名变量。

文档字符串写在函数体第一行，用三引号，说明参数和返回值。

推导式

print([n * n for n in range(5)])
print([n for n in range(10) if n % 2 == 0])
print({n: n * n for n in range(3)})

输出 [0, 1, 4, 9, 16]、[0, 2, 4, 6, 8]、{0: 0, 1: 1, 2: 4}。超过一行就改回普通 for。
