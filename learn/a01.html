Python 从第一行执行到最后一行。print(...) 把结果打到屏幕。# 后面是注释，不执行。

= 是赋值，把右边的值贴到左边的名字上。== 是比较，结果是 True 或 False。

输出：

3 是整数，"3" 是字符串，类型不同，不相等。

第 1 天：比较和布尔

六个比较：==、!=、>、<、>=、<=。

and 要求两边都成立。or 只要一边成立。not 取反。

输出依次是 True、True、True、False、False、True、False。

在条件里，这些当成假：0、0.0、""、[]、{}、None、False。非空字符串、非零数字当成真。所以 bool(0) 是 False，bool("0") 是 True。"0" 不是空字符串，它是一个字符。

第 3 天：分支

if / elif / else 从上到下，只走第一条成立的分支。缩进 4 个空格是语法的一部分。

顺序必须是：先看是不是数字文本，再 int，再看是否超过 100，再分等级。先 int("abc") 会抛 ValueError，程序停在那里。

等级：90 到 100 是优秀，60 到 89 是及格，0 到 59 是不及格。其余都提示错误，不输出等级。

如果把 >= 60 写在 >= 90 前面，90 分会在第一条就被判成及格，优秀那一支永远走不到。

输入结果
0、59不及格
60、89及格
90、100优秀
101、-1错误，不输出等级
abc、空字符串、60.5错误，不崩溃，不输出等级

-1 里有负号，isdecimal 为假，所以在转换之前就被挡下。

电脑上写 d03_grade.py，按上表处理一次输入。通过之后，不看这一页，把优秀线改成 85，确认 85 走优秀、84 走及格。

第 4 天：for 和统计变量

range(start, stop) 含起点，不含终点。range(1, 6) 是 1、2、3、4、5，一共五个数。

累加器和计数器写在循环外面。写在循环里面，每轮都会被重新设成 0。

输出：

1 到 10 的和是 55。55 到 65 里至少 60 的是 60、61、62、63、64、65，共 6 个。

电脑上写 d04_for.py，只用变量和 range，先不要用列表和 sum。再改成 1 到 5 求和、遍历 59 到 61，先预测再运行。口头说明 range(1, 6) 有几个数。

第 5 天：while、退出和跳过

次数事先不知道，用 while。break 离开整个循环。continue 跳过本轮剩下的语句，回到循环开头再读下一次输入。

三组自己走一遍：

  • 60 → abc → 90 → q：有效个数 2。abc 在 continue 处回到开头，不会给 valid 加 1。
  • 直接 q：有效个数 0。
  • 101 → -1 → Q：有效个数 0。Q 被 lower 变成 q。

每轮都要重新 input。如果把 input 放在循环外面，程序会拿同一段文字一直转。按停止按钮杀掉进程，不算正常退出。

电脑上写 d05_while.py。今天只统计有效个数，平均分明天再加。主动造一个写错变量名的错误，看 Traceback 最后一行的文件和行号。

第 6 天：合成这个工具

文件名 score_cli.py。规则：

  • 持续读入 0 到 100 的整数成绩，允许首尾空格。q 或 Q 退出。
  • 负数、小数、空输入、非数字、大于 100，都提示错误，不计入统计。
  • 退出时输出有效个数、及格个数、不及格个数、平均分。及格线 60。0 算不及格，100 算及格。
  • 一次都没有有效成绩时，输出「暂无有效成绩」，不能做除法。
  • 同一个分数录入两次，算两次。

循环外面准备四个变量：有效个数、及格个数、不及格个数、总分。退出之后，有效个数是 0 就只提示；否则平均分是总分除以有效个数，用 f"{avg:.2f}" 保留两位小数。

测试依次输入预期
T0159 → 60 → 100 → q有效 3，及格 2，不及格 1，平均 73.00
T02q有效 0，暂无有效成绩
T03abc → -1 → 101 → 60 → q有效 1，及格 1，不及格 0，平均 60.00
T04首尾有空格的 60 → Q有效 1，及格 1，平均 60.00
T0560.5 → q有效 0，暂无有效成绩
T060 → 100 → q有效 2，及格 1，不及格 1，平均 50.00
T0760 → 60 → q有效 2，及格 2，平均 60.00
T08空字符串 → q有效 0，暂无有效成绩

73.00 是 (59 + 60 + 100) / 3。50.00 是 (0 + 100) / 2。

第 7 天：改一条规则

把及格线放进变量，先设成 70。输入 69 → 70 → q，结果是有效 2、及格 1、不及格 1、平均 69.50。再改回 60，把上面八组重跑一遍。

用自己的话讲清五件事：为什么 input 之后要先校验再转换；统计变量为什么放在循环外；什么时候用 for、什么时候用 while；break 和 continue 差在哪；没有成绩时为什么不能直接算平均分。
