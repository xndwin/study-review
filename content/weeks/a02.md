## 列表

列表 `[...]` 有顺序、可增删改：
- **下标从 `0` 开始**，负数从末尾倒数（`-1` 是最后一项）。
- **切片 `xs[起点:终点]`**：含头不含尾（`scores[0:2]` 取 `0` 号和 `1` 号）。

```python
scores = [59, 60, 100]
print(scores[0], scores[-1])   # 59 100
print(scores[0:2])             # [59, 60]

scores.append(80)              # 末尾追加
print(sorted(scores))          # 返回排好序的【新列表】，原列表不变
scores.sort()                  # 原地重排原列表，返回值是 None
print(scores)                  # [59, 60, 80, 100]
```

**两条避坑规矩**：
1. 不要写 `xs = scores.sort()`（得到的是 `None`）；要新列表用 `sorted(scores)`。
2. 不要在 `for x in scores:` 里直接增删 `scores`；过滤数据时新建空列表再 `append`。

**元组 `(1, 2)`**：创建后不可修改的序列。单元素元组必须加逗号写 `(1,)`；`a, b = (1, 2)` 叫拆包赋值。

## 第 1 周留下的字符串

字符串同样支持下标和含头不含尾切片，只是不能原地修改某个字符：

```python
s = "Python"
print(s[0], s[-1], s[0:2], len(s))     # P n Py 6
print("th" in s)                       # True（包含子串）
print("a,b".split(","))                # ['a', 'b']（按分隔符拆成列表）
print("-".join(["a", "b"]))            # 'a-b'（把字符串列表拼回字符串）
print("python".find("th"))             # 2（找不到时返回 -1，不报错）
```

## 字典和集合

### 字典 `{"键": 值}`

按名字标签查找数据。键可能不存在时用 **`.get(键, 默认值)`**，避免直接写 `d["键"]` 抛 `KeyError` 崩溃：

```python
person = {"name": "王敏", "score": 90}
print(person["name"])                  # 王敏
print(person.get("email", "(无)"))     # (无)
person["score"] = 91                   # 改值或新增键值
```

层层取嵌套数据（如大模型接口返回结果）从左往右剥：`resp["choices"][0]["message"]["content"]`。

### 集合 `set`

自动去重、无固定顺序。注意**空集合必须写 `set()`**（`{}` 是空字典）：

```python
seen = set()
for word in ["rag", "sql", "rag"]:
    seen.add(word)
print(sorted(seen))                    # ['rag', 'sql']
```

## 循环的另外三种写法

```python
names = ["王敏", "李雷"]
for i, name in enumerate(names, start=1):   # 同时拿编号和元素
    print(i, name)

for name, score in zip(names, [90, 61]):    # 两个序列并排配对遍历
    print(name, score)
```

补充语法：
- **循环后的 `else:`**：仅在循环正常跑完、中途**没触发 `break`** 时执行。
- **短路求值**：`and / or` 左边能决定结果时不算右边，返回最后看过的原值（如 `"" or "默认"` 得 `"默认"`）。
- **判空值 `None`**：统一写 `score is None` 或 `score is not None`。
- **单行三元条件**：`"及格" if score >= 60 else "不及格"`（复杂分支仍写普通多行 `if`）。

## 函数

### `print` vs `return`

- **`print`** 只是印在屏幕上给人看；
- **`return`** 才把计算结果真正交还给调用方（没写 `return` 的函数默认返回 `None`）。

```python
def average(total, count):
    if count == 0:
        return None
    return total / count

print(average(219, 3))   # 73.0
print(average(0, 0))     # None
```

### 可变默认参数陷阱

默认参数**不要写 `=[]` 或 `={}`**（多次调用会共用同一个列表）。标准写法是用 `None` 进函数再新建：

```python
def add_score(scores=None):
    """把 60 加入列表并返回。"""
    if scores is None:
        scores = []
    scores.append(60)
    return scores
```

## 推导式

把简单的单层转换/过滤浓缩成一行（超过一行或逻辑复杂时改回普通 `for`）：

```python
print([n * n for n in range(5)])               # [0, 1, 4, 9, 16]
print([n for n in range(10) if n % 2 == 0])    # [0, 2, 4, 6, 8]
print({n: n * n for n in range(3)})            # {0: 0, 1: 1, 2: 4}
```
