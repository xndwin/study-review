# 第 5 周：HTTP 与 FastAPI

计划日期：2026-12-14 到 2026-12-20。

这一周做一个工单服务的第一版，数据先放在内存里。你要能用 `/docs` 或 curl 调通创建、查询、列表、修改，并分清参数错误、找不到、服务自己出错。

## 一次请求里有什么

HTTP 请求有方法、路径、标头、正文。

- `GET` 读取，不改数据。
- `POST` 新建。
- `PATCH` 改一部分字段。
- 路径 `/tickets/3` 里的 `3` 是资源编号。
- 正文用 JSON，标头里写 `Content-Type: application/json`。

常见状态码：

| 码 | 含义 | 例子 |
|---|---|---|
| 200 | 成功并带回内容 | 查到一张工单 |
| 201 | 已创建 | 新建成功 |
| 404 | 没有这个资源 | 编号不存在 |
| 422 | 正文或参数不合格 | 标题是空的 |
| 500 | 服务自己出错 | 代码抛了未处理的异常 |

422 是调用方写错了。404 是编号对不上。500 是你的程序有 bug，不要把「找不到」写成 500。

## 一个最小服务

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI()
tickets: dict[int, dict] = {}
next_id = 1

class TicketIn(BaseModel):
    title: str = Field(min_length=1, max_length=80)
    user_id: int = Field(ge=1)

@app.post("/tickets", status_code=201)
def create_ticket(body: TicketIn):
    global next_id
    item = {"id": next_id, "title": body.title, "user_id": body.user_id, "status": "open"}
    tickets[next_id] = item
    next_id += 1
    return item

@app.get("/tickets/{ticket_id}")
def get_ticket(ticket_id: int):
    item = tickets.get(ticket_id)
    if item is None:
        raise HTTPException(status_code=404, detail="未找到")
    return item
```

`user_id` 从 `body.user_id` 取。写成一个不存在的名字，函数一跑就是 `NameError`，调用方看到的是 500，不是 422。

Pydantic 在函数运行前检查类型和 `min_length`。标题是空字符串，FastAPI 直接回 422，函数体不会执行。

启动：

```bash
uvicorn app:app --reload
```

浏览器打开 `http://127.0.0.1:8000/docs`。也可以：

```bash
curl -s -X POST http://127.0.0.1:8000/tickets \
  -H 'Content-Type: application/json' \
  -d '{"title":"无法登录","user_id":1}'
```

列表用 `GET /tickets`，返回目前字典里的值。修改用 `PATCH /tickets/1`，只允许改 `title` 或 `status`，状态先限定 `open` 和 `closed`。未知状态回 422。

在 `ticket-service` 里实现创建、按编号查询、列表、修改标题或状态。准备四次调用并记下状态码：
