w02-1 虚拟环境与 pip

系统自带的 Python 不要直接往里装一堆包。虚拟环境是「本项目专用的 Python」。

cd 仓库根目录
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

提示符前面出现 (.venv) 才算激活。装包：pip install 包名。冻结合：pip freeze > requirements.txt（本仓库已经写好，不要随便覆盖）。

pip list 查看已装。升级 pip：python -m pip install -U pip。

w02-2 文件、编码、pathlib、with

文本要指定编码，中文用 utf-8。路径用 pathlib.Path，少手写斜杠。

from pathlib import Path
p = Path("data/w05/notes.md")
p.exists()
p.read_text(encoding="utf-8")
p.write_text("内容", encoding="utf-8")
p.parent.mkdir(parents=True, exist_ok=True)

旧式 open 必须关文件。with 会在离开块时自动关：

with open(p, "r", encoding="utf-8") as f:
    for line in f:
        print(line.rstrip())

模式："r" 读，"w" 覆盖写，"a" 追加。二进制（以后读 PDF 原始字节）用 "rb"。

Path(__file__) 是当前脚本路径。Path(__file__).parent / "sample.txt" 不依赖你在哪个目录敲命令——示例里都用这个。

跑：python code/w02/01_files.py

w02-3 JSON

JSON 是 API 和配置的通用格式：对象 {}、数组 []、字符串必须双引号。

Python 对照：

JSONPython
objectdict
arraylist
stringstr
numberint/float
true/falseTrue/False
nullNone
import json
s = json.dumps({"model": "deepseek-chat"}, ensure_ascii=False, indent=2)
obj = json.loads(s)

ensure_ascii=False 才能在文件里直接看到中文。indent=2 方便人读。

从文件：json.loads(path.read_text(encoding="utf-8")) 写入：path.write_text(json.dumps(obj, ensure_ascii=False, indent=2), encoding="utf-8")

模型经常返回「像 JSON 的字符串」，还可能包 ```json 代码块，要用字符串剥掉再 loads。非法 JSON 会 json.JSONDecodeError。

跑：python code/w02/02_json.py

w02-4 异常与 Traceback

出错会抛异常。不接住，程序停，终端打印 Traceback。

从下往上看 Traceback：最后一行才是错误类型和原因，上面是谁调用了谁。

try:
    n = int("x")
except ValueError as e:
    print("转换失败", e)

常见：ValueError TypeError KeyError IndexError FileNotFoundError json.JSONDecodeError ZeroDivisionError。

  • 先抓具体类型，不要一上来 except Exception 全吞掉（会把真正的 bug 藏起来）
  • except A as e 里 e 是错误对象
  • raise 重新抛出；raise RuntimeError("说明") from e 保留因果（llm.py 里用过）
  • finally：无论成功失败都执行（关资源）；有 with 时较少手写 finally

跑：python code/w02/03_errors.py

w02-5 默认参数、可变默认值、类型注解入门

默认参数必须放后面。可变对象（list/dict）不要当默认值，见第 1 周陷阱。正确：

def add_msg(history=None):
    if history is None:
        history = []
    ...

类型注解（给人和编辑器看，不强制运行时检查）：

def mean(nums: list[float]) -> float:
    ...

Optional[str] 或 str | None 表示可以是 None。后面 FastAPI / Pydantic 会强制检查请求体类型。

w02-6 类

类把「数据 + 操作」捆在一起。RAG 的检索器、Agent 的工具箱都会长成这样。

class TokenBudget:
    def __init__(self, limit: int):
        self.limit = limit
        self.used = 0

    def add(self, n: int) -> bool:
        if self.used + n > self.limit:
            return False
        self.used += n
        return True
  • __init__ 构造
  • self 是当前实例
  • self.used 是实例自己的数据，两个对象互不影响
  • 方法第一个参数必须是 self（调用时不用传）

和函数的区别：函数是「拿参数算一次」；对象是「记得自己上次到哪了」。

继承先混个眼熟即可：class FileRetriever(Retriever):。本周不要求会写复杂继承。

跑：python code/w02/04_class.py

w02-7 模块与入口

一个 .py 就是一个模块。import json 是标准库。import openai 是第三方（先 pip）。

同目录导入：文件名必须是合法标识符（不要用 01_chat.py 当模块名去 import 01_chat）。所以公共客户端放在 code/w03/llm.py。

from pathlib import Path
import sys
sys.path.insert(0, str(Path(__file__).resolve().parent))
from llm import chat

这是教学用写法。以后正规项目用包（带 __init__.py）或 pip install -e .。

if __name__ == "__main__":
    main()

直接 python 文件.py 时 __name__ 是 "__main__"；被别人 import 时不是。避免 import 时立刻跑演示代码。

w02-8 HTTP 与 JSON 响应

调大模型本质是：对某个 URL 发 HTTP POST，body 是 JSON，回来也是 JSON。SDK 帮你做了这些。自己发一次能建立直觉。

# GET 示例
from urllib.request import urlopen
with urlopen("https://httpbin.org/get") as resp:
    body = resp.read().decode("utf-8")

本机练习不依赖外网：code/w02/06_http_local.py 只演示「如何组 JSON 请求体」（不真发）。真发在第 3 周用 SDK。

你要记住的字段：url、method、headers（Authorization）、body。401 多半是 Key；404 是路径；429 是限流。
