列表

列表有顺序，可以改。下标从 0 开始，负数从末尾数。切片含头不含尾。

sorted(scores) 交出一个新列表，原来的不变。scores.sort() 改的是原来那一个，返回 None。把 print(scores.sort()) 印出来会看到 None，这是常见错法。

不要在 for x in scores 里面 append 或 remove 正在遍历的那个列表。要过滤，就建一个新列表。

元组写成 (1, 2)，创建之后不能改某一项。只有一个元素时必须写 (1,)，否则括号只是分组。a, b = (1, 2) 叫拆包。

字典和集合

字典用键取值。键不存在时，person["email"] 抛 KeyError。person.get("email", "(无)") 给出默认值。

sorted(seen) 是 ['rag', 'sql']。集合自动去重，不保证顺序。空集合写成 set()。{} 是空字典，不是空集合。

循环的另外三种写法

enumerate 同时给出序号和元素，序号默认从 0 开始。zip 把两个序列并排走到较短的那个结束。

for / while 可以带 else。这个 else 只在循环没有被 break 打断时执行。搜一个名单，找到就 break，没找到才走 else。

and / or 会短路：左边已经能决定结果，右边就不算。0 or 5 的值是 5，3 and 7 的值是 7。它们不一定返回 True / False，返回的是最后那个被看过的操作数。

和 None 比较用 is：score is None。== 问的是值相不相等，is 问的是是不是同一个对象。

三元表达式："及格" if score >= 60 else "不及格"。能改写成普通 if 就先用普通 if。

print 给人看。return 把值交给下一行代码。函数里如果只 print，调用方拿到的是 None，没法继续算。
