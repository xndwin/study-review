  1. = 和 == 各做什么？
  2. 3 > 2

  4. 3 != 4
  5. 5 >= 5
  6. 2 < 1
  7. True and False
  8. False or True

  10. bool(0) 和 bool("0") 是否相同？为什么？

再写三句：成绩至少 60；成绩在 0 到 100 之间；字符串不是空的。

  4. True
  5. True
  6. False
  7. False。and 要两边都成立。
  8. True。or 有一边成立即可。
  9. False
  10. 不相同。0 是假；"0" 不是空字符串，是真。

score >= 60；0 <= score <= 100；text != ""。

第 2 天 · a01-d02 输入与字符串

学 input、strip、lower、isdecimal、f-string。输入进来都是字符串。方法要写括号，结果要接住。

文件 d02_input.py：读姓名和成绩文本，打出原文、去掉首尾空格后的文本、长度、能不能当作整数字符串。再把 " Q " 去空格并转小写。

自测样本：" 60 "、""、"abc"、"60.5"、" Q "。

预期
  • " 60 " 去掉空格是 "60"，可以当整数。
  • 空字符串和 "abc" 不是整数文本。
  • "60.5" 含小数点，isdecimal() 为假。今天不要对它直接 int。
  • " Q " 去掉空格再小写是 "q"。
  • 去掉空格不等于已经检查过是不是合法成绩。

第 3 天 · a01-d03 分支

先看是不是整数字符串，再 int，再看范围和等级。0–100 才接受。90–100 优秀，60–89 及格，0–59 不及格。其余提示错误。

文件 d03_grade.py。每个输入单独运行一次。

预期
  • 0、59：不及格
  • 60、89：及格
  • 90、100：优秀
  • 101、-1、abc、空字符串、60.5：错误，不输出等级，也不因转换崩溃

同一条 elif 链里如果先写 >= 60，90 分会在到达优秀之前就被及格接走。

第 4 天 · a01-d04 for

range 不含终点。累加和计数在循环外设成 0。文件 d04_for.py：1 到 10 的和；55 到 65 里至少 60 的个数。先不要用列表和 sum。

预期
  • 1 到 10 的和是 55。
  • 55 到 65 里至少 60 的有 6 个：60 到 65。
  • range(1, 6) 是 1、2、3、4、5，共 5 个数。
  • 1 到 5 的和是 15。59 到 61 里至少 60 的有 2 个。
  • 计数器如果写在循环里面并每轮归零，最后只会剩 0 或 1。

第 5 天 · a01-d05 while

文件 d05_while.py。一直读成绩。去空格、转小写后是 q 就退出。合法成绩打印等级并计入个数。非法的提示错误，不计入，然后继续读下一次。

预期
  • 60 → abc → 90 → q：有效 2 个。
  • 直接 q：有效 0 个。
  • 101 → -1 → Q：退出，有效 0 个。
  • break 结束整段循环。continue 跳过这一轮剩下的步骤。退出要靠 q，不是靠停掉程序。

第 6 天 · a01-d06 成绩工具

文件 score_cli.py。持续录入 0–100 的整数，q／Q 退出。非法输入只提示，不进统计。退出时给出有效个数、及格个数、不及格个数和平均分。及格线 60。没有有效成绩时说明暂无，不能除以零。相同分数录入两次算两次。

8 组预期
输入结果
59 → 60 → 100 → q有效 3，及格 2，不及格 1，平均 73.00
q有效 0，暂无有效成绩
abc → -1 → 101 → 60 → q有效 1，及格 1，不及格 0，平均 60.00
带首尾空格的 60 → Q有效 1，及格 1，平均 60.00
60.5 → q有效 0，暂无有效成绩
0 → 100 → q有效 2，及格 1，不及格 1，平均 50.00
60 → 60 → q有效 2，及格 2，平均 60.00
空字符串 → q有效 0，暂无有效成绩
