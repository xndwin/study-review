## w08-1 FastAPI

脚本是给你自己跑的；HTTP 接口是给前端、评测脚本、同事用的。

```bash
cd 仓库根目录
source .venv/bin/activate
uvicorn projects.api:app --reload
```

打开 http://127.0.0.1:8000/docs

- `@app.get("/health")` 探活
- `@app.post("/rag")` 请求体用 Pydantic 模型校验 `{"question": "..."}`  
  缺字段或类型不对会自动 422，不必手写一堆 if

`projects/api.py` 内部仍调用 `ask()`。以后 Agent 可再加 `POST /agent`。

概念：路由、请求/响应 JSON、OpenAPI 自动文档、校验。本周不要求鉴权、部署到云，但要知道上线还差：HTTPS、Key、限流、日志。
