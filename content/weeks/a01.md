## 程序怎么往下走

Python 从第一行执行到最后一行。`print(...)` 把结果打到屏幕。`#` 后面是注释，不执行。

`=` 是赋值，把右边的值贴到左边的名字上。`==` 是比较，结果是 `True` 或 `False`。

```python
score = 60
print(score == 60)
print(3 == "3")
```

输出：

```text
True
False
```

`3` 是整数，`"3"` 是字符串，类型不同，不相等。

## 第 1 天：比较和布尔

六个比较：`==`、`!=`、`>`、`<`、`>=`、`<=`。

`and` 要求两边都成立。`or` 只要一边成立。`not` 取反。

```python
print(3 > 2)
print(3 != 4)
print(5 >= 5)
print(2 < 1)
print(True and False)
print(False or True)
print(not True)
```

输出依次是 `True`、`True`、`True`、`False`、`False`、`True`、`False`。

在条件里，这些当成假：`0`、`0.0`、`""`、`[]`、`{}`、`None`、`False`。非空字符串、非零数字当成真。所以 `bool(0)` 是 `False`，`bool("0")` 是 `True`。`"0"` 不是空字符串，它是一个字符。


## 第 2 天：输入和字符串

`input("提示:")` 返回的永远是字符串。用户输入 `60`，你得到的是 `"60"`，还不能拿来和数字比大小。

字符串不能原地改某个字符。方法返回的是新字符串，原来的还在。

```python
raw = "  Q "
cleaned = raw.strip().lower()
print(repr(raw))
print(cleaned)
print("60".isdecimal())
print("60.5".isdecimal())
print("-1".isdecimal())
print("".isdecimal())
name = "王敏"
print(f"你好，{name}")
```

输出：

```text
'  Q '
q
True
False
False
False
你好，王敏
```

`strip` 去掉首尾空白，不改中间。`lower` 把字母变成小写。`isdecimal` 只在字符串非空、并且每个字符都是十进制数字时为真。小数点、负号、空串都不算。`repr` 用来看见空格还在不在。

## 第 3 天：分支

`if` / `elif` / `else` 从上到下，只走第一条成立的分支。缩进 4 个空格是语法的一部分。

顺序必须是：先看是不是数字文本，再 `int`，再看是否超过 100，再分等级。先 `int("abc")` 会抛 `ValueError`，程序停在那里。

等级：90 到 100 是优秀，60 到 89 是及格，0 到 59 是不及格。其余都提示错误，不输出等级。

```python
raw = " 90 "
text = raw.strip()
if not text.isdecimal():
    print("错误")
else:
    score = int(text)
    if score > 100:
        print("错误")
    elif score >= 90:
        print("优秀")
    elif score >= 60:
        print("及格")
    else:
        print("不及格")
```

如果把 `>= 60` 写在 `>= 90` 前面，90 分会在第一条就被判成及格，优秀那一支永远走不到。

| 输入 | 结果 |
|---|---|
| 0、59 | 不及格 |
| 60、89 | 及格 |
| 90、100 | 优秀 |
| 101、-1 | 错误，不输出等级 |
| abc、空字符串、60.5 | 错误，不崩溃，不输出等级 |

`-1` 里有负号，`isdecimal` 为假，所以在转换之前就被挡下。

## 第 4 天：for 和统计变量

`range(start, stop)` 含起点，不含终点。`range(1, 6)` 是 1、2、3、4、5，一共五个数。

累加器和计数器写在循环外面。写在循环里面，每轮都会被重新设成 0。

```python
total = 0
for n in range(1, 11):
    total = total + n
print(total)

passed = 0
for n in range(55, 66):
    if n >= 60:
        passed = passed + 1
print(passed)
```

输出：

```text
55
6
```

1 到 10 的和是 55。55 到 65 里至少 60 的是 60、61、62、63、64、65，共 6 个。

## 第 5 天：while、退出和跳过

次数事先不知道，用 `while`。`break` 离开整个循环。`continue` 跳过本轮剩下的语句，回到循环开头再读下一次输入。

```python
valid = 0
while True:
    raw = input("成绩，q 退出: ")
    text = raw.strip().lower()
    if text == "q":
        break
    if not text.isdecimal():
        print("错误")
        continue
    score = int(text)
    if score > 100:
        print("错误")
        continue
    print(score)
    valid = valid + 1
print("有效", valid)
```

三组自己走一遍：

- `60 → abc → 90 → q`：有效个数 2。`abc` 在 `continue` 处回到开头，不会给 `valid` 加 1。
- 直接 `q`：有效个数 0。
- `101 → -1 → Q`：有效个数 0。`Q` 被 `lower` 变成 `q`。

每轮都要重新 `input`。如果把 `input` 放在循环外面，程序会拿同一段文字一直转。按停止按钮杀掉进程，不算正常退出。

## 第 6 天：合成这个工具

文件名 `score_cli.py`。规则：

- 持续读入 0 到 100 的整数成绩，允许首尾空格。`q` 或 `Q` 退出。
- 负数、小数、空输入、非数字、大于 100，都提示错误，不计入统计。
- 退出时输出有效个数、及格个数、不及格个数、平均分。及格线 60。0 算不及格，100 算及格。
- 一次都没有有效成绩时，输出「暂无有效成绩」，不能做除法。
- 同一个分数录入两次，算两次。

循环外面准备四个变量：有效个数、及格个数、不及格个数、总分。退出之后，有效个数是 0 就只提示；否则平均分是总分除以有效个数，用 `f"{avg:.2f}"` 保留两位小数。

| 测试 | 依次输入 | 预期 |
|---|---|---|
| T01 | 59 → 60 → 100 → q | 有效 3，及格 2，不及格 1，平均 73.00 |
| T02 | q | 有效 0，暂无有效成绩 |
| T03 | abc → -1 → 101 → 60 → q | 有效 1，及格 1，不及格 0，平均 60.00 |
| T04 | 首尾有空格的 60 → Q | 有效 1，及格 1，平均 60.00 |
| T05 | 60.5 → q | 有效 0，暂无有效成绩 |
| T06 | 0 → 100 → q | 有效 2，及格 1，不及格 1，平均 50.00 |
| T07 | 60 → 60 → q | 有效 2，及格 2，平均 60.00 |
| T08 | 空字符串 → q | 有效 0，暂无有效成绩 |

73.00 是 `(59 + 60 + 100) / 3`。50.00 是 `(0 + 100) / 2`。
