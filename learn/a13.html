第 13 周：切块、元数据、文档版本

计划日期：2027-02-08 到 2027-02-14。

项目一：用公开的产品手册、使用说明，或你自己写的售后政策，做知识库问答。先选一个范围小的场景，记下资料从哪来、能不能用。

这一周只做到：文件能读进来，切成块，每块知道自己出自哪一页或哪一节。解析失败要报出来，不能变成一份空资料还继续问答。

先文本，再 PDF

Markdown 和纯文本用 pathlib 按 utf-8 读取。PDF 只处理能抽出文字的那种。扫描件没有文字层时，记录「这一份抽不出文字」，不要当成空字符串成功。

每份文档有一个稳定的 doc_id。重新导入同一份时沿用这个编号，并增加版本号。删除是把这个 doc_id 标成不可用，或真的删掉它的块。问答不能再返回已删除版本的句子。

一块要保存的元数据：

  • doc_id、版本、文件名
  • 块序号
  • 原文位置：页码，或标题路径
  • 这块的文字

切块

检索的单位是块，不是整篇。块太大，一段里混进很多无关句子。块太小，一句话被切断。相邻块重叠一段，是为了答案正好落在切缝上时，至少有一块是完整的。

def chunk_text(text: str, size: int = 400, overlap: int = 80) -> list[str]:
    if overlap >= size:
        raise ValueError("重叠必须小于块长")
    chunks = []
    start = 0
    while start < len(text):
        piece = text[start:start + size].strip()
        if piece:
            chunks.append(piece)
        if start + size >= len(text):
            break
        start += size - overlap
    return chunks

这里的长度先按字符数练习。真正接入模型前，再对照那家对上下文长度的说明。中文按字符切和按 token 切不是一回事，笔记里写明你用的是哪一种。

抽查三块：每块都能指回文件和位置；重叠处的句子在相邻两块里都能看到。

这一周自己写

准备大约 20 份短资料，先全部是 Markdown。导入命令打印：成功几份、失败几份、共多少块。

故意放进一个空文件和一个编码错误的文件。输出里要有文件名和原因，成功的那些仍然入库。

验收：随机抽一块，能打开原文件找到这段话。删掉一个 doc_id 之后，按这个编号查块，结果是空的。

写程序仍在电脑上。新开对话只发：先读 主文件.md，从书签继续。
