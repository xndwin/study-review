第 17 周：工具调用

计划日期：2027-03-08 到 2027-03-14。

项目二处理模拟售后工单：查询规则和状态，生成处理草稿，等人确认之后才改数据库。数据和业务都是模拟的。

这一周用普通 Python 把「分类 → 查询 → 生成草稿」跑通，接上至少 3 个受控工具。简历上这一周可以叫做工具调用。ReAct 只是讲解时的词，指模型交替想下一步和查看工具结果。代码不必先上某个 Agent 框架。

点开一章：先合上写一句规则和一个自己的例子，再对照全文。错的留在那一章，第 1、3、7、14 天再做。
