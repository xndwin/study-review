第 7 周：分层、归属校验、接口测试

计划日期：2026-12-28 到 2027-01-03。

这一周把「路由、数据库、规则」分开，并证明用户 A 读不到用户 B 的工单。外部输入仍然不能拼进 SQL。

三层

  • 路由：解析 HTTP，调用下面的函数，把结果或错误码送回去。不在这里写 SQL。
  • 服务：决定能不能改状态、这张工单是不是这个人的。
  • 数据：只执行带来参数的 SQL，返回行。

请求从接口进来，经过服务，到数据库，再原路返回。你要能对着一个 GET /tickets/3 把这三步指出来。

归属

练习阶段用一个请求头模拟登录用户，例如 X-User-Id: 2。这不是正式登录，只用来把「当前是谁」送进服务。没有这个头，回 401。

404 表示没有这张工单。403 表示有，但不属于你。两种都不要把对方的标题回出去。

先查「存在吗」再查「是不是你的」，调用方就能知道编号是否被人占用。练习里可以都回 404，避免透露别人的编号。两种做法选一种，在 README 写明，测试按你写的来。

测试不要碰开发库

TestClient 在进程里调用接口，不需要先手动启动 uvicorn。测试用另一个数据库文件，或者内存库 sqlite:///:memory: 这一周先用临时文件，测完删除。

还要有：正常创建后能查到；缺标题是 422；编号不存在是 404；不带用户头是 401。

开发时你自己点的 app.db 和测试库分开。测试开头建表，不要往练习数据里插入「测试工单」。

同步和异步

FastAPI 路径函数写成普通 def，阻塞的 SQL 可以放在里面，框架会把它放到线程池。写成 async def 之后，里面如果直接调用会卡住的数据库驱动，就会堵住整个事件循环，别的请求一起等。

这一周用同步的 sqlite3 加普通 def。不要为了看起来现代，把阻塞调用塞进 async def 又不 await 一个真正的异步驱动。
