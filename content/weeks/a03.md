## 路径和编码

不要把系统 Python 当成项目环境。项目用仓库根目录的 `.venv`。终端里先 `source .venv/bin/activate`，提示符前面出现 `(.venv)` 再装包、再运行。

中文文件用 `utf-8`。路径用 `pathlib`。`Path(__file__)` 是当前脚本自己的位置，不随你在哪个目录敲命令而改变。

```python
from pathlib import Path

here = Path(__file__).resolve().parent
source = here / "sample.csv"
target = here / "out" / "summary.txt"
target.parent.mkdir(parents=True, exist_ok=True)
text = source.read_text(encoding="utf-8")
target.write_text(text, encoding="utf-8")
```

`"w"` 会清空目标文件再写。输出写到新文件，例如 `out/summary.txt`。读的那个 `sample.csv` 不要用 `"w"` 打开。

`with` 离开代码块时自动关文件：

```python
with source.open("r", encoding="utf-8") as f:
    for line in f:
        print(line.rstrip("\n"))
```

## CSV 和 JSON

CSV 第一行当表头。用标准库 `csv`，不要自己按逗号切开，因为字段里也可能有逗号。

```python
import csv
from pathlib import Path

with Path("feedback.csv").open(encoding="utf-8", newline="") as f:
    rows = list(csv.DictReader(f))
print(rows[0]["name"])
```

JSON 的对象对应字典，数组对应列表。`json.dumps` 把字典变成文本，`json.loads` 把文本变回字典。中文要 `ensure_ascii=False`，否则文件里会变成 `\u4e2d`。

```python
import json
payload = {"name": "王敏", "score": 90}
raw = json.dumps(payload, ensure_ascii=False)
print(raw)
print(json.loads(raw)["score"])
```

文件坏了会抛 `json.JSONDecodeError`。捕获之后打印文件名和「这一份跳过」，继续下一份。不要用光秃秃的 `except:`，那会把键盘中断也吞掉。

## Traceback

报错从下往上看。最后一行是异常类型和说明，上面最近的一条带你的文件名和行号，就是你先该看的位置。

```python
def parse_file(path):
    try:
        return json.loads(Path(path).read_text(encoding="utf-8"))
    except FileNotFoundError:
        print(f"找不到 {path}")
    except UnicodeDecodeError:
        print(f"编码不是 utf-8：{path}")
    except json.JSONDecodeError as exc:
        print(f"JSON 坏了：{path} 第 {exc.lineno} 行")
    return None
```

这三种失败都返回 `None`，调用方决定跳过，不把半截结果写回原文件。

## 模块

一个文件就是一个模块。想在命令行直接运行，又想被别的文件导入，把「真正开跑」放进：

```python
def main():
    print("开始统计")

if __name__ == "__main__":
    main()
```

别人 `import` 这个文件时，`__name__` 不是 `"__main__"`，`main` 不会自动跑。文件名用 `summarize.py` 这种字母，不要用 `01_files.py` 当被导入的模块名，因为模块名不能以数字开头。

## Git 只记四件事

在练习项目目录里：

```bash
git init
git status
git add summary.py
git commit -m "读取一份 CSV 并打印行数"
git diff
git checkout -b try-json
```

`status` 看哪些文件改了。`diff` 看改了哪几行。`commit` 留下一个可以回去的点。试验新格式时开分支 `try-json`，坏了就回到原来的分支，原始数据文件不要提交进「覆盖实验」。

密钥文件 `.env` 不要 `git add`。
