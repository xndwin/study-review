第 17 周 工具调用

本页目录谁执行工具

谁执行工具

你声明工具的名字、说明和参数 schema。模型返回它想调用的名字和参数。真正执行的是你的 Python。模型进不了你的电脑，也不能自己写 SQL。

旧字段 function_call 不要照抄。现在用 tools / tool_calls。

循环是：

  1. 把 tools 和当前 messages 发给 Chat Completions。
  2. 如果 message.tool_calls 是空的，content 就是给用户的话，结束。
  3. 否则解析每个调用的 JSON 参数，在白名单里找函数。
  4. 把模型那条消息放回历史，再追加 role 为 tool 的结果，带上 tool_call_id。
  5. 再请求，直到没有工具调用，或达到最大步数。

白名单之外的名字，返回「没有这个工具」，不要用 getattr 去摸任意函数。
