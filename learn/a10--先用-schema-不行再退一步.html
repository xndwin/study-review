先用 schema，不行再退一步

课文已遮住 · 先回想重点再核对

供应商支持时，response_format 用 json_schema，并打开严格模式。这样模型更不容易漏字段或加字段。

不支持时，退到 json_object，或者在提示里要求只输出一个 JSON 对象。json_object 只保证整体是 JSON，不保证有 kind 这个键，也不保证 kind 属于那三个词。

两种都要在你的代码里再查一遍：

业务规则不交给 schema 一个人管。例如「描述至少 4 个字」仍写在 accept 里。

模型有时用 Markdown 代码块包住 JSON。json.loads 之前，如果文本以三个反引号开头，先去掉首尾的围栏行。去完仍不是 JSON，就拒绝，不要把原文直接存成提取结果。

提示词写成仓库里的一个文本文件，一次只做提取这一件事。少样本最多放两个，一个正常，一个应当转人工。样本和评测题不要用同一句。
