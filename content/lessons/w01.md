## w01-2 变量、命名、类型、转换、运算

变量是贴在对象上的名字：

```python
name = "王敏"
age = 24
gpa = 3.70
ok = True
```

命名：字母/数字/下划线，不能以数字开头；不要用 `list` `str` `type` 当名字。习惯：小写加下划线 `max_tokens`。

`type(x)` 看类型。常用：`int` `float` `str` `bool`。

转换：

```python
int("10")      # 10
float("3.5")   # 3.5
str(10)        # "10"
int(3.9)       # 3  （截断，不是四舍五入）
int("hi")      # ValueError
```

算术：`+ - * /` ；`/` 永远得到 float（`7/2 == 3.5`）。  
整数除：`//`（`7//2 == 3`）。余数：`%`。幂：`**`。

赋值增强：`n += 1` 等于 `n = n + 1`。

**`=` 是赋值，`==` 是比较是否相等。** 写错会得到语法错或永远 True 的 bug。

## w01-3 布尔、比较、逻辑、真值

比较：`== != > < >= <=`  
身份：`is` / `is not`（判断是不是同一个对象；和 `None` 比较用 `is`：`x is None`）

逻辑：`and` `or` `not`。`and`/`or` 短路：前面已经能决定结果就不算后面。

在 if 里，这些相当于 False：`0` `0.0` `""` `[]` `{}` `None` `False`。  
非空字符串、非零数字、非空容器相当于 True。

```python
items = []
if not items:
    print("空")
```

## w01-4 输入与字符串

`input("提示:")` 得到的**永远是 str**。要当数字必须 `int(...)`，转换失败会 ValueError（猜数字里已示范）。

字符串是不可变序列：

```python
s = "Python"
s[0]        # 'P'
s[-1]       # 'n'
s[0:2]      # 'Py'  含头不含尾
s[::2]      # 步长 2
len(s)      # 6
"th" in s   # True
```

不能写 `s[0] = "p"`，要拼新字符串。

常用方法（都返回新串，不改原串）：

```python
"  hi\n".strip()
"Hello".lower()          # hello
"a,b,c".split(",")       # ['a','b','c']
",".join(["a", "b"])     # 'a,b'
"rag rag".replace("rag", "RAG")
"file.md".endswith(".md")
"abc".find("b")          # 1 ；找不到返回 -1
```

f-string：

```python
score = 72
msg = f"分数是 {score}，及格={score >= 60}"
```

转义：`\n` 换行，`\t` 制表，`\\` 反斜杠。原始字符串 `r"C:\tmp"` 少用转义。

缩进 4 空格是语法。嵌套 if 能用但别超过两层，再深就拆函数。

```python

```

`if` 后面其实是在用「真值」，所以 `if xs:` 表示列表非空。

## w01-6 循环

```python
for i in range(3):        # 0,1,2
    print(i)
for i in range(1, 5, 2):  # 1,3
    print(i)

n = 3
while n > 0:
    n -= 1
```

`range(start, stop, step)` 不含 stop。

```python
names = ["a", "b"]
for i, name in enumerate(names, start=1):
    print(i, name)

for x, y in zip([1, 2], ["一", "二"]):
    print(x, y)
```

- `break`：立刻离开循环
- `continue`：跳过本轮剩余语句
- `for`/`while` 可以带 `else`：循环**没有被 break** 才执行（猜数字里「次数用完」就是这种）

在 for 里增删**正在遍历的列表**容易漏元素或报错。要改就先拷贝：`for x in xs[:]:` 或先建新列表。

## w01-7 列表、元组

列表可变、有序、可重复：

```python
xs = [3, 1, 2]
xs.append(4)
xs.insert(0, 0)
xs.pop()          # 删最后一个并返回
xs.remove(1)      # 按值删第一次出现
xs.sort()         # 原地排序
sorted(xs)        # 返回新列表
xs[0] = 99
len(xs)
sum(xs)
min(xs); max(xs)
```

切片同样含头不含尾：`xs[1:3]`。

列表里可以套列表：`matrix = [[1, 2], [3, 4]]`，`matrix[1][0] == 3`。

元组有序但不可变：`t = (1, 2)`。常用于「返回多个值」：`return mean, n`。单元素元组必须写 `(1,)`。

拆包：`a, b = (10, 20)`。

## w01-8 字典、集合、嵌套

字典：键必须不可变（str/int/tuple），值随意。

```python
person = {"name": "王敏", "skills": ["python"]}
person["skills"].append("rag")
person.get("age", 0)     # 没有键时默认 0，不抛错
person["age"] = 24
"name" in person
for k, v in person.items():
    print(k, v)
for k in person.keys():
    ...
for v in person.values():
    ...
```

用 `[]` 取不存在的键会 `KeyError`，所以配置常用 `.get`。

集合：去重、无序、`in` 很快：

```python
s = {1, 2, 2}     # {1,2}
s.add(3)
{1, 2} & {2, 3}   # 交
{1, 2} | {2, 3}   # 并
```

空集合必须 `set()`，`{}` 是空字典。

嵌套在 LLM 里极常见：

```python
resp = {"choices": [{"message": {"content": "你好"}}]}
text = resp["choices"][0]["message"]["content"]
```

## w01-9 函数、返回值、作用域、文档字符串

```python
def mean(nums):
    """算术平均。空列表返回 0.0。"""
    if not nums:
        return 0.0
    return sum(nums) / len(nums)
```

- `return` 把值交回调用者；没有 return 相当于返回 `None`
- 不要用 print 代替 return：print 给人看，return 给下一行代码用
- 一个函数尽量一件事；名字用动词或名词短语
- 默认参数必须在普通参数后面：`def chat(user, temperature=0.2):`
- 不要用 `[]` 或 `{}` 当默认值（可变对象会在多次调用间共享）。要用 `None` 再在里面新建

作用域：函数内赋值的变量默认是局部的，看不见外面的同名变量（除非 `global`，应用代码里尽量别用 global）。

多个返回值其实是元组：

```python
def stats(xs):
    return min(xs), max(xs), sum(xs) / len(xs)

lo, hi, avg = stats([1, 2, 9])
```

```python
mapping = {n: n * n for n in range(3)}
```
