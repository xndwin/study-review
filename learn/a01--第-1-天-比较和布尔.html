布尔值（bool）只有两个：True（真） 和 False（假）。注意在代码里首字母必须大写。

1. 六个比较符号

符号中间不能加空格：

写法意思例子结果
==等于5 == 5True
!=不等于3 != 4True
> / <大于 / 小于2 < 1False
>=大于或等于（至少）5 >= 5True
<=小于或等于（至多）60 <= 100True

2. 逻辑连接：and、or、not

  • and（并且）：左右都为 True 才得 True，有一边假就是 False。
  • or（或者）：左右至少一边为 True 就得 True。
  • not（取反）：真变假，假变真。

3. 真假转换规则：bool(...)

记住两句话：数字看是不是 0，字符串只看空不空。

  • 数字：0 和 0.0 是 False，其余非零数字都是 True → bool(0) 为 False。
  • 字符串：只有没字符的空串 "" 是 False；只要引号里有字符（哪怕写的是 "0"、"False" 或空格 " "），一律是 True → bool("0") 为 True。
