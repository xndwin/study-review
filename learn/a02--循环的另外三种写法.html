循环的另外三种写法

enumerate 同时给出序号和元素，序号默认从 0 开始。zip 把两个序列并排走到较短的那个结束。

for / while 可以带 else。这个 else 只在循环没有被 break 打断时执行。搜一个名单，找到就 break，没找到才走 else。

and / or 会短路：左边已经能决定结果，右边就不算。0 or 5 的值是 5，3 and 7 的值是 7。它们不一定返回 True / False，返回的是最后那个被看过的操作数。

和 None 比较用 is：score is None。== 问的是值相不相等，is 问的是是不是同一个对象。

三元表达式："及格" if score >= 60 else "不及格"。能改写成普通 if 就先用普通 if。
