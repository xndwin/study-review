现行学法（2026-11-17）

课文 lessons/ 不删。学到调用模型、结构化输出、RAG 和工具时，以这一页和供应商当天的文档为准。模型名、域名、价格和某个参数是否支持都会变，写进代码前打开官方页核对。

这一页只记录应用开发还在用的接口。预训练、推理引擎和多 Agent 平台仍不作为这半年的主线。

2026-11-17 核对过的来源：

  • Migrate to the Responses API：OpenAI 新项目用 Responses。Chat Completions 仍可用。Assistants API 已于 2026-08-26 停用。
  • Chat Completions：页面写明新项目去看 Responses。
  • DeepSeek 第一次调用：同时给出 OpenAI 兼容和 Anthropic 兼容。当天示例模型是 deepseek-flash。
  • DeepSeek 聊天机器人：Messages、Responses、Chat Completions 三条路径都列着。
  • DeepSeek 工具调用：工具仍由调用方执行；思考模式和普通模式的限制不同。
  • 通义 OpenAI 兼容 Chat：当天仍用 Chat Completions。base_url 带业务空间，按账号地域从帮助页抄。
  • 通义多轮对话：Chat Completions 的历史要自己拼；Responses 被标成另一条更省事的多轮路径。
  • LangGraph interrupts、checkpointers。
