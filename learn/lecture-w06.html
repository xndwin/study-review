w06-1 多文件加载

ask.py 扫描 code/test/rag-qa/data/ 下全部 .md / .txt，分别切块并带上 source=文件名。至少 2 个文件，合计建议 1500 字以上，否则检索没有区分度。不要放密钥、未公开数据、别人的付费课。

现有：notes.md、about.md。

w06-2 问答与来源

输出必须包括：命中的块编号、来源文件、分数、模型回答。回答里应有 [编号]。空命中要能看出「无」。复用 code/w05/rag_core.py。若改用 retrieve_cosine，只在 ask.py 换函数，生成 prompt 不用动。

w06-3 README

别人只看 README 要能：安装、配 .env、如何提问、如何评测、架构、已知问题。架构覆盖：加载 → 切块 → 检索（写明词重叠还是余弦）→ 生成 → 拒答 → 你负责哪几层。已写满：code/test/rag-qa/README.md。

w06-4 评测 10 条

建议：5 条资料里有明确答案；3 条应拒答；2 条易混。eval.py 的 CASES 已 10 条。离线目标 ≥ 8/10（当前自检 10/10）。通过率写入第 6 周笔记。

w06-5 已知问题

至少 2 条真实失败写进 README。面试会问失败，没有失败记录反而不像做过。当前已写：专有名词切碎、同义词召回不足、离线抽取文笔较差。

资料正文不要写「本公司营收」「考试答案」这类句子，否则拒答题会被检索命中（污染）。拒答只写「检索为空必须拒绝编造」。
